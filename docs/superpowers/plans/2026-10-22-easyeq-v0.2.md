# EasyEQ v0.2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship EasyEQ v0.2 features: polished DMG installer + app icon, paint-style editing for dense band layouts, 10 built-in presets, user preset groups, import/export, shortcuts, launch at login, test-build CI.

**Architecture:** Same three-target Swift package. New pure logic (presets, groups, transfer, painting math, smoothing) goes in `EasyEQCore` with Swift Testing tests; UI in `Sources/EasyEQ/Views`; packaging in `scripts/` + `.github/workflows/`.

**Tech Stack:** Swift 6 toolchain (language mode 5), SwiftUI/AppKit, ServiceManagement (`SMAppService`), Swift Testing, bash, `dmgbuild` (Python, build-time only), GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-22-easyeq-v0.2-design.md` (Chinese, binding). Previous specs still apply: `2026-10-21-easyeq-design.md`, `2026-10-21-ui-restyle.md`.

## Global Constraints

- Work on branch `feat/v0.2`. **Never push, never tag, never merge to main** — the user tests first (see spec §1.6).
- macOS 14.4 minimum; Swift language mode 5; no new runtime dependencies (build-time `dmgbuild` only).
- Every visible string goes through `Localizer.t`; every new key is added to BOTH `Sources/EasyEQCore/Resources/{en,zh-Hans}.lproj/Localizable.strings` (key-parity test must pass).
- All colors come from `Sources/EasyEQ/Views/Theme.swift` (light + dark); no hard-coded colors in views.
- Animations: only short (≤0.2 s) transitions on discrete actions; nothing while dragging/painting; nothing looping.
- Backward compatibility: v0.1 preset JSON files (no `groupID`) and settings must load unchanged.
- No changes to audio DSP behaviour.
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- `swift test` passes, without warnings, after every task.

## Review Focus

1. **Old data**: a v0.1 preset file (no `groupID`) and a missing `groups.json` must load as ungrouped, and a corrupt `groups.json` must not lose presets. → Task 2 tests.
2. **Deleting a group never deletes presets**; deleting a preset that is the only member leaves an empty group, not a crash. → Task 2 tests.
3. **Fast horizontal painting must not skip bands** and must work right-to-left. → Task 4 tests.
4. **Importing bad / duplicate / same-name files** must import the good ones, rename duplicates, regenerate clashing IDs, and report failures. → Task 3 tests.
5. **DMG built on CI (headless)** must still have its background and icon layout — `dmgbuild` writes `.DS_Store` without Finder. → Task 8 verification.

### Task 4: Painting math and smoothing

**Files:** Create `Sources/EasyEQCore/BandPainter.swift`; Modify `Sources/EasyEQCore/EQSettings.swift`; Test `Tests/EasyEQCoreTests/BandPainterTests.swift`, `EQSettingsTests.swift`.

**Interfaces:**
- `public struct BandPainter { public init(bandCount: Int, width: Double, height: Double, range: Double = 12) }` — columns are equal-width over `width`; y=0 is +range, y=height is −range.
  - `func band(atX x: Double) -> Int` (clamped to `0..<bandCount`)
  - `func gain(atY y: Double) -> Double` (clamped to ±range)
  - `func stroke(from: (x: Double, y: Double), to: (x: Double, y: Double)) -> [(index: Int, gain: Double)]` — every band whose column is between the two points (inclusive, either direction), with gain linearly interpolated along the segment at that column's centre (the end band uses `to`'s y). A purely vertical move returns just the band under `to`.
- `EQSettings.smoothed() -> EQSettings` — 3-tap weights 0.25/0.5/0.25 (ends: 0.75/0.25 with the single neighbour), rounded to 0.1 and clamped; layout unchanged. `EQSettings.zeroed() -> EQSettings`.

- [ ] Step 1: failing tests — `bandAndGainMapping` (31 bands over width 310: x=5→0, x=305→30, x=999→30; y=0→+12, y=height→−12, mid→0), `fastStrokeCoversEveryBand` (x 5→305 in one step covers 31 indices in order with interpolated gains), `strokeRightToLeft`, `verticalStrokeIsSingleBand`, `smoothingSoftensSpike` (single +12 spike in flat → neighbours 3, centre 6), `smoothedFlatStaysFlat`, `zeroed`.
- [ ] Step 2: run → FAIL; implement; `swift test` → PASS. Commit `feat: band painting math and smoothing`.
