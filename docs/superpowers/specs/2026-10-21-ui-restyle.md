# EasyEQ 界面改版（方案 B：浅色玻璃，清淡版）

日期：2026-10-21
状态：作者已确认方向（“B，稍微清淡一点，不要那么重；深色和浅色模式都要，用户可在软件里切换”）

## 目标

把目前“纯功能”的界面改成清淡、优雅的玻璃风格（参考 CleanMyMac 的渐变 + 玻璃 + 大圆角），并提供浅色/深色两套外观。**只改外观，功能、布局、操作方式不变。**

## 反目标

- 不要持续运行的动画或高帧率效果；界面静止时零开销。
- 不要浓重的饱和色、强发光；整体要“轻”。
- 不改变任何音频、预设、保存逻辑。

## 外观设置（新功能）

- 设置里新增“外观 / Appearance”：跟随系统 / 浅色 / 深色。默认跟随系统。切换立即生效（主窗口和设置窗口都变）。
- 持久化到 `AppSettings`（新增字段 `appearance`）。**旧版本存的设置里没有这个字段时，其余设置（语言、上次预设等）必须保留**——`AppSettings` 解码要对每个字段用 `decodeIfPresent` + 默认值。
- 实现方式：`NSApp.appearance = nil / NSAppearance(named: .aqua) / .darkAqua`。

## 配色（设计令牌）

所有颜色集中在一个文件（如 `Sources/EasyEQ/Views/Theme.swift`），按浅色/深色两套定义，视图不写死颜色。

| 令牌 | 浅色 | 深色 |
|---|---|---|
| 窗口背景渐变（左上→右下，三段） | `#F6F8FF` → `#F9F6FF` → `#F4FBF9` | `#16182A` → `#1A1730` → `#121F1F` |
| 侧边栏底色 | 白色 50% 透明 | 白色 4% |
| 卡片底色 | 白色 85% | 白色 6% + 1pt 白色 8% 内描边 |
| 卡片阴影 | `#3C46A0` 6%，半径 16，下移 4 | 无 |
| 主文字 | `#1D2340` | `#ECEEFA` |
| 次文字 | `#6B7192` | `#9AA0BF` |
| 强调渐变（曲线、滑块填充、开关、保存按钮） | `#6E7CFF` → `#45C9BA` | `#8090FF` → `#52D6C7` |
| 选中预设 | 白色卡片 + 轻阴影，文字用强调色起始色 | 白色 10% + 强调色文字 |

圆角：窗口内卡片 14pt，侧边栏选中项 9pt，按钮 8pt。

## 组件

- **窗口**：隐藏标题栏（内容延伸到顶部，红绿灯浮在左上），整个窗口铺背景渐变。
- **侧边栏**：分组标题小字次文字色；每个预设前一个 8pt 彩色圆点：人声 `#6E7CFF`、人声·强 `#9B7CFF`、原声 `#45C9BA`；用户预设按列表顺序循环 `#FFB36B, #FF8FB1, #5BC0FF, #8BD86A, #C79BFF`。底部“＋ 新建预设”。
- **标题区**：预设名 20pt 粗体；内置预设名下方一行说明（次文字色、11pt）；用户预设不显示说明。右侧：段数切换做成药丸形分段（选中段白底/深色下白 15%），效果开关用强调色。
- **曲线卡片**：0 dB 虚线；曲线 2.5pt 强调渐变描边；下方填充用起始色 18%→0% 的竖向渐变。
- **滑块卡片**：轨道 6pt 圆角（浅色 `#1E285A` 8%，深色白 12%）；从 0 线到圆点的填充用强调渐变；圆点 18pt 白色、2pt 强调起始色描边、轻阴影；数值在上（强调起始色、半粗），名称+频率在下（次文字色）。
- **底部**：左边设备名（前面一个小圆点）+ 已有的状态/重试/权限链接；右边“另存为…”“恢复”用浅底按钮，“保存”用强调渐变药丸按钮。
- **横幅/弹窗/设置窗口**：沿用同一套令牌，风格一致。

## 动画

- 只在操作瞬间：切换预设、切换段数、恢复时，滑块与曲线用 0.2 秒 easeOut 过渡；选中态、开关淡入淡出。
- 拖动滑块时不加动画（完全跟手）。
- 没有任何循环或常驻动画。

## 新增文案（中/英，两份字符串表都要有）

| key | zh-Hans | en |
|---|---|---|
| preset.voice.desc | 压掉闷音，让说话更清楚 | Less boom, clearer speech |
| preset.voicePlus.desc | 人声特别闷的时候用 | For very muddy voices |
| preset.flat.desc | 不做任何处理 | No processing |
| settings.appearance | 外观 | Appearance |
| appearance.light | 浅色 | Light |
| appearance.dark | 深色 | Dark |

（“跟随系统”复用已有的 `settings.system`。）

## 验收

1. 浅色、深色、跟随系统三种外观下截图，主窗口与设置窗口风格一致、文字清楚、对比度足够。
2. 10 / 15 / 31 段在最小窗口宽度下都排得下。
3. 拖动滑块跟手无延迟；切换预设有柔和过渡；静止时 CPU 无额外占用。
4. 升级后旧设置（语言、上次预设、段数）不丢失。
5. `swift test` 全部通过。
