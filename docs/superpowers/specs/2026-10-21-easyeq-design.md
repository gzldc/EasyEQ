# EasyEQ（简易均衡器）设计文档

日期：2026-10-21
状态：待确认

## 1. 为什么做这个

作者用 Mac Studio + Studio Display 的显示器扬声器看视频和直播。Studio Display 本身低频偏厚，碰上人声本来就浑的视频，说话声发闷、听着累。作者想要一个**系统级均衡器**：把低音压一压、咬字提一提，存几个预设随时切换。

试过的软件都不理想：

- **Sonora**：功能刚好满足，但界面上有每天 30 分钟的付费倒计时，用着心烦。
- **Radioform**（开源、免费）：常驻菜单栏，面板很小；频段只标数字（32、64……），看不懂是干什么的；保存的“自定义”预设实际全是 0 dB 且被禁用，存了等于没存；改频率、Q 值要双击进高级面板。整体不直观。

EasyEQ 要做的，就是 **Sonora 那样顺手、Radioform 那样免费开源**，并且让不懂音频的人一看就会用。项目开源到 GitHub。

## 2. 目标

1. 对 Mac 上**所有播放的声音**生效（浏览器直播、视频网站、播放器等），不需要安装音频驱动。
2. 一个**独立窗口**的普通 Mac App：左边预设列表，右边竖向滑块（界面方案 A）。
3. **直接拖滑块，声音实时变化**；每个滑块上方显示当前 dB 数值，下方写中文/英文大白话名称 + 频率。
4. 滑块上方有一条**实时整体响应曲线**，拖任意滑块曲线立即跟着变，让用户看到“哪一片声音被压下去了”。
5. 频段数可选：**10 段（默认）/ 15 段 / 31 段**，都是行业标准的图示均衡器频点。
6. 预设：内置 3 个（人声、人声·强、原声），用户可新建、保存、另存、改名、删除。**存了就真的生效**。
7. 界面语言：简体中文 + 英文。默认跟随系统；系统既非中文也非英文时用英文；可在设置里手动切换。
8. 完全免费，没有任何倒计时、付费墙、功能锁。

## 3. 非目标（第一版不做）

- 不常驻菜单栏，不做菜单栏小弹窗。
- 不做按 App 分别均衡（只对整个系统声音生效）。
- 不做参数均衡（频率可移动、Q 值可调、滤波器类型可选）、AutoEQ 耳机校正、空间音频、音效、混响。
- 不支持 Windows / Linux / iOS。
- 不上架 Mac App Store（见第 9 节）。

## 4. 反目标（做出来也算失败的情况）

- 出现任何“免费额度”“试用倒计时”“升级专业版”。
- 需要用户安装内核扩展或 HAL 音频驱动、手动去“声音设置”里切换输出设备。
- 改一个频段需要先双击、再进二级面板。
- 保存的预设和听到的声音对不上（Radioform 的问题）。
- 关掉窗口声音就恢复原样（用户已明确：关窗口效果继续）。
- 收集任何用户数据或联网统计。

## 5. 约束

- 语言与框架：**原生 Swift + SwiftUI**（作者决定）。
- 平台：**仅 macOS**（作者决定）。最低版本 **macOS 14.4**（与 Sonora 一致；系统音频捕获 API 在该版本可用且稳定）。
- 目标机器：Apple Silicon（作者是 Mac Studio）；Intel 机器能编译运行即可，不专门优化。
- 首次启动需要系统的“音频录制/系统音频”权限，这是 macOS 规定，绕不开；要在 App 里用一句话说明为什么需要。

## 6. 作者已经决定的事

### 6.1 App 形态
- 普通窗口 App，有 Dock 图标，**不常驻菜单栏**。
- **关闭窗口 ≠ 退出**：关窗口后均衡效果继续，App 留在 Dock；点 Dock 图标重新打开窗口；**⌘Q 退出后才停止处理**，声音恢复原样。

### 6.2 主窗口布局（方案 A）

```
┌───────────────────────────────────────────────────────────┐
│ ● ● ●                     EasyEQ                          │
├──────────────┬────────────────────────────────────────────┤
│ 内置          │  人声                      效果开关 [●━]    │
│  ▸ 人声  ✓    │  ┌──────────────────────────────────────┐  │
│    人声·强    │  │      实时整体响应曲线                 │  │
│    原声       │  └──────────────────────────────────────┘  │
│ 我的预设       │   -6   -5   -4   -3   -1   0  +2 +2.5 0  0 │
│    晚上直播    │   ┃    ┃    ┃    ┃    ┃    ┃   ┃   ┃  ┃  ┃ │
│              │   ●    ●    ●    ●    ●    ●   ●   ●  ●  ● │
│ ＋ 新建预设    │  重低音 低音 浑厚 发闷 人声 人声 咬字 清晰 齿音 空气│
│              │   32   64  125  250  500  1K  2K  4K  8K 16K│
│              │                       [恢复]  [保存]        │
└──────────────┴────────────────────────────────────────────┘
```

- 左侧：预设列表，分“内置”和“我的预设”两组，底部“＋ 新建预设”。
- 右侧：当前预设名、效果总开关、响应曲线、竖向滑块、“恢复”“保存”按钮。
- 段数切换（10/15/31）放在右侧顶部或设置里（实现者决定位置，但必须一眼能找到）。

### 6.3 滑块操作
- **按住直接拖，松手即生效，拖动过程中声音实时变化**；不需要双击进入编辑。
- 拖动要顺滑跟手（不卡顿、不跳格）。
- 范围 **−12 dB ～ +12 dB**，0 dB 处有中线和轻微吸附。
- **双击滑块 = 该段归零**（常见软件的通用习惯）。

### 6.4 频段
| 模式 | 频点 |
|---|---|
| 10 段（默认） | 32、64、125、250、500、1K、2K、4K、8K、16K |
| 15 段 | 25、40、63、100、160、250、400、630、1K、1.6K、2.5K、4K、6.3K、10K、16K |
| 31 段 | ISO 1/3 倍频程：20、25、31.5、40、50、63、80、100、125、160、200、250、315、400、500、630、800、1K、1.25K、1.6K、2K、2.5K、3.15K、4K、5K、6.3K、8K、10K、12.5K、16K、20K |

- 切换段数时，按**当前整体曲线**在新频点上取值，声音尽量保持不变，不清零。
- **段数属于预设**（作者已确认）：
  - 每个用户预设记住自己的段数和每段数值；选中它时，界面自动切到该段数，听到的和保存时完全一样，不做换算。
  - 内置预设以 10 段数值定义；选中内置预设时沿用界面当前段数，按曲线换算显示。
  - 在某个预设上切换段数，算作“未保存改动”（显示小圆点）；点“保存”就以新段数覆盖，点“恢复”回到原段数和原数值。
  - App 记住的“上次段数”只用于下次打开时的初始界面和新建预设的默认段数。
- 10 段模式下每个滑块显示大白话名称（中/英）：

| 频点 | 中文 | 英文 |
|---|---|---|
| 32 | 重低音 | Sub-bass |
| 64 | 低音 | Bass |
| 125 | 浑厚 | Warmth |
| 250 | 发闷 | Muddiness |
| 500 | 人声 | Body |
| 1K | 人声 | Voice |
| 2K | 咬字 | Presence |
| 4K | 清晰 | Clarity |
| 8K | 齿音 | Sibilance |
| 16K | 空气感 | Air |

  15/31 段滑块太窄，只显示频率；鼠标悬停时显示所属区域名称。

### 6.5 预设
- 内置（只读）：
  | 预设 | 10 段数值（dB，32→16K） |
  |---|---|
  | 人声 | −6, −5, −4, −3, −1, 0, +2, +2.5, 0, 0 |
  | 人声·强 | −10, −9, −7, −5, −2, 0, +3, +3, 0, −1 |
  | 原声 | 全部 0（等同关闭） |

  这两组人声数值来自对话中给作者在 Radioform 里设好并试听过的值；15/31 段下按曲线换算。
- 用户预设：新建、保存（覆盖当前用户预设）、另存为、改名、删除。
- 修改内置预设后点“保存” → 提示“内置预设不能覆盖，另存为新预设”，并直接给出命名输入框。
- 有未保存改动时，预设名旁显示一个小圆点；“恢复”回到上次保存的值。
- App 记住：上次使用的预设、效果开关状态、段数、语言。下次打开自动恢复并立即生效。

### 6.6 语言
- 支持 **简体中文** 和 **英文**。
- 默认跟随系统首选语言：中文（任何简体/繁体中文地区）→ 中文；英文 → 英文；其他语言 → 英文。
- 设置里可手动选择：跟随系统 / 中文 / English。切换后界面立即更新（若技术上必须重启，需明确提示）。
- 内置预设名也要翻译（人声 → Voice，人声·强 → Voice+，原声 → Flat）。

### 6.7 名字
- 英文名 **EasyEQ**，中文名 **简易均衡器**。已查：Mac App Store 无同名；GitHub 有一个 8 星、已不活跃的同名仓库；无同类商业产品冲突。

## 7. 技术方向（我的建议，作者未表态，可由实现者调整）

- **系统声音获取**：使用 Core Audio 的进程音频捕获（Process Tap，`CATapDescription`），全局捕获所有进程的输出并让原声静音；把捕获的声音交给自己的处理链，再输出到当前默认输出设备（例如 Studio Display Speakers）。这样**不需要安装驱动、也不需要用户切换输出设备**。Sonora 用的就是这类方式（同样要求 macOS 14.4+ 和系统音频权限）。
- **均衡算法**：每个频段一个二阶峰值滤波器（RBJ Audio EQ Cookbook 的 peaking biquad），串联；10 段 Q≈1.41，15 段 Q≈2.1，31 段 Q≈4.3（与常见图示均衡器一致）。
- **防爆音**：自动前级衰减（按曲线最大正增益自动降低总电平）+ 轻量限幅器，用户无需看到“Pre”滑块。
- **参数切换不出杂音**：滤波器系数平滑过渡，拖滑块时不能有咔哒声。
- **输出设备**：跟随系统默认输出；系统切换输出设备（插耳机、换显示器）时自动跟随；窗口里显示当前设备名。
- **预设存储**：JSON 文件，放在 `~/Library/Application Support/EasyEQ/Presets/`，格式里写明段数和版本号，方便以后扩展。
- **延迟与占用**：处理延迟应短到看视频时察觉不到口型不同步（目标 < 20 ms）；CPU 占用在 Apple Silicon 上应很低。

## 8. 留给实现者决定的事

- 段数切换控件的具体位置和样式（只要一眼能找到）。
- 响应曲线的绘制细节（颜色、坐标刻度、是否显示网格）。
- 设置窗口的具体形式（标准 Settings 场景即可）。
- 预设 JSON 的具体字段名。
- App 图标（第一版可用简单的图形占位）。
- 工程组织（Xcode 工程或 Swift Package + App target）、测试框架。

## 9. 发布与开源（我的建议，作者未表态）

- 许可证：**MIT**（我的建议，最宽松、最常见）。
- 发布方式：GitHub Releases 提供 `.zip`/`.dmg`。
- **签名：第一版不用付费开发者账号签名，只做本机临时签名（ad-hoc），不公证**（作者决定：“先不签名，以后再说”）。
  - README 写明首次打开的步骤：macOS 15 起“右键 → 打开”已不能绕过，要到“系统设置 → 隐私与安全性”里点“仍要打开”。
  - README 写明：更新版本后可能需要重新授予系统音频权限。
  - 构建脚本把“签名身份”做成可配置项，以后有了 Developer ID，只需在 GitHub Secrets 里加证书，就能像 Radioform 的 `release.yml` 那样自动签名 + 公证，不用改代码。
- 无论哪种签名方式，App 都要能检测到“系统音频权限”丢失或未授予，并在窗口里明确提示、提供一键跳转到系统设置的按钮，而不是默默没有效果。
- README 提供中英双语说明、截图、权限说明、卸载方法（删掉 App 和 `~/Library/Application Support/EasyEQ` 即可）。

## 10. 怎样算做好了

1. 打开 App、授予权限后，浏览器里的视频/直播声音立刻被均衡处理，无需其他设置。
2. 选“人声”，Studio Display 上说话明显不再发闷；切到“原声”或关闭开关，声音与不开 App 时一致。
3. 拖任一滑块，声音和曲线同时实时变化，无咔哒声、无卡顿。
4. 新建预设 → 调整 → 保存 → 退出 App → 重新打开，选这个预设，听到的和保存时一样。
5. 关闭窗口后效果仍在；⌘Q 后声音恢复原样。
6. 切换 10/15/31 段，声音基本不变。
7. 系统语言为中文时界面是中文，为英文/日文等时为英文；手动切换后立即生效。
8. 插拔耳机或切换输出设备后，效果自动跟到新设备上。
