# EasyEQ v0.2 设计文档

日期：2026-10-22
状态：作者要求“规划一下，然后直接开始实现”；以下“我的决定”均为替作者做的取舍，可在验收时推翻。

## 1. 这次要解决的问题（作者原话归纳）

1. **安装体验**：打开 DMG 时，要像别的软件一样有“拖到‘应用程序’即可安装”的引导界面。
2. **31 段太密**：一个个点、离得太近，操作不友好；15 段也偏挤。
3. **预设太少**：应该内置更多效果。
4. **预设多了要能分组**：支持“分组（Group）”，可折叠；默认不分组，只有用户手动才新建分组。
5. **更全面一些**：作者让我规划其他该补的东西。
6. （延续上次）**先测试、再发布**：新功能先在分支上给作者试用，不自动推送、不自动发版。

## 2. 目标

### 2.1 安装界面（DMG）
- 打开 `EasyEQ-<版本>.dmg` 时，Finder 弹出一个整洁的安装窗口：左边 EasyEQ 图标，右边“应用程序”文件夹，中间一个箭头，下方一句中英双语提示“把 EasyEQ 拖到‘应用程序’即可安装 / Drag EasyEQ to Applications to install”。
- 背景用和 App 一致的浅色柔和渐变；窗口约 640×420，图标 128pt，隐藏工具栏和侧边栏；DMG 卷标图标用 App 图标。
- **我的决定**：只做“拖拽安装”，不做 .pkg 安装向导。原因：单个 App 的业界标准就是拖拽 DMG；安装向导需要管理员权限、反而更重，也不需要。
- **App 图标**：目前是系统默认的空白图标，DMG 里会很难看。新做一个图标：macOS 圆角方形，蓝→青斜向渐变底，白色的均衡曲线 + 三个白色滑块圆点。图标由仓库里的脚本生成（可重复生成），不依赖外部设计工具。

### 2.2 密集频段的操作方式（重点）
- **刷过去就能改（我的决定，核心方案）**：在滑块区域按住鼠标**横向拖动**，经过的每一段都会被设成鼠标当前的高度——像用画笔“画”出曲线。竖着拖时仍然只改手下那一段，和现在一样。快速划过也不会漏段（相邻两次采样之间的段按直线插值补齐）。10 / 15 / 31 段都可用。
- **在曲线上直接画**：曲线卡片同样支持按住拖动来画，横坐标对应频率，纵坐标对应增益。
- **悬停提示**：鼠标停在某一列上，这一列高亮，并浮出小气泡“1.25K · +3.0 dB”。
- **滚轮微调**：鼠标停在某一列上滚动（或触控板双指上下），每格 ±0.5 dB。
- **31 段减负**：底部频率标签只显示一半（隔一个显示一个），其余靠悬停气泡查看，不再挤成一团。
- **两个辅助按钮**（放在段数切换旁）：
  - “平滑”：把曲线做一次轻微平滑（相邻三段加权平均），画完 31 段后一点就顺。
  - “归零”：所有段归 0（可用“恢复”撤回）。
- 双击滑块归零保持不变。

### 2.4 预设分组
- **默认不分组**：用户自己的预设平铺在“我的预设”下面，和现在一样。
- **新建分组只能手动**：侧边栏底部“＋”变成菜单：新建预设 / 新建分组 / 导入预设…。
- 分组标题：左侧折叠箭头、分组名、右侧数量；点击标题折叠/展开；右键：重命名、删除分组、在此分组新建预设。
- **删除分组不会删除里面的预设**：预设自动回到“我的预设”（不分组），所以删除分组不需要二次确认。
- 把预设放进分组：右键“移到分组 ▸”（列出所有分组 + “不分组”），或直接把预设**拖到**分组标题上。
- “内置”区域本身也可以折叠；所有折叠状态都会记住，下次打开保持。
- 新建预设时，如果当前选中的预设在某个分组里，新预设默认放进同一个分组（我的决定，符合直觉）。
- 方向键上下切换预设时，跳过被折叠隐藏的预设。

### 2.5 其他补全（我的决定）
1. **删除预设前确认**：现在右键删除会直接永久删除，加一个确认对话框。
2. **导入 / 导出预设**：右键“导出…”把预设存成 `.json` 文件；“＋ → 导入预设…”可一次选多个文件导入。导入时自动处理重名（加“ 2”）和重复 ID（重新生成），坏文件给出提示、不影响其他文件。方便分享和备份。
3. **快捷键**：⌘N 新建预设、⌘S 保存、⇧⌘S 另存为、⌘E 打开/关闭效果。
4. **开机自动启动**：设置里加开关（默认关）。均衡器通常希望一直生效，这样不用每次手动打开。
5. **启动卡顿**：每次启动/切换设备时界面会卡约 1 秒（上次审查遗留），把那一步挪到后台。
6. **测试包与测试版**：
   - GitHub 上新增“测试构建”：手动点一下就能为任意分支打出测试用 DMG（只作为构建产物下载，不出现在 Releases）。
   - 版本标签里带 `-`（如 `v0.2.0-beta.1`）时自动标为“预发布”，不会成为“最新版本”。

## 3. 非目标
- 不做 .pkg 安装向导、不做菜单栏常驻、不做按 App 分别均衡、不做参数均衡（可移动频点 / Q 值）、不做自动更新。
- 不改音频处理核心逻辑。

## 4. 反目标
- 操作变复杂：新交互必须“不学也会用”——竖着拖还是原来的效果，横着拖只是更省事。
- 预设或分组数据丢失：任何分组操作都不能删除预设；旧版本保存的预设必须能直接读取（没有分组信息 = 不分组）。
- 未经作者同意推送到 main 或发布版本。

2. 31 段下：横向一划就能改出一条曲线；悬停能看到频率和数值；滚轮能微调；标签不再挤；“平滑”“归零”可用。
3. 内置预设 10 个，名称、说明、数值与 §2.3 一致，中英文都对。
4. 能新建、重命名、删除分组；拖动或右键把预设放进分组；折叠状态重启后保持；删除分组后预设还在。
5. 能导出、导入预设；删除预设有确认；快捷键可用；开机启动开关可用。
